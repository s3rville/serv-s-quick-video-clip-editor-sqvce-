[OPEN SOURCE] Cut, trim, merge video clips quickly with ease without launching a heavy program. Made for memes, gaming clips and similar basic use cases. Tired of not having a reliable program to do tasks that should take seconds? This is the answer for all of your problems. I made it for myself and everyone else too. Enjoy.

Feature list
--
- Import multiple videos onto the project ✅
- Lazy cache imported videos in the background for better performance ✅
- Cut/Trim, Merge Videos ✅
- Double click on clips in the timeline for individual settings ✅
   - Mute audio
   - Change playback speed
   - Mirror video
   - Reverse playback
   - Mini Icon to display status per-clip
- Thumbnails on the timeline ✅
- Smooth/adaptive video scrubbing ✅
- Performance Warnings ✅
- Cropping tool ✅
  - With adaptive Aspect ratio and manual input
- Resize tool ✅
  - With adaptive Aspect ratio and manual input
- Support for mobile aspect ratios etc. ✅
- Screenshot current frame of the video ✅
- Frame by Frame seek ✅
- Lossless cuts/trims and merges by using "Snap" Mode ✅
- Transcode videos for smaller file sizes ✅
- Reformat videos ✅
- Import/Export and Optimize gifs with Lossygif in the GIF mode ✅
- Quick share menu after Export ✅
- Presets for Encoding and custom presets ✅
- Ability to add Images ❌
- Preferences Tab ❌
- Choose background/blank color ❌
- Audio Tab ❔
- Support for very long videos in the timeline ❌
- [QOL] Focus on playhead when zooming in-out on the timeline ❌
- Bookmarks/labels ❌
- Text Tool ❌
- [QOL] Shift click on Export to instantly Export next to the original file ❌
- Set default save location ❌
- Set export naming scheme ❌
- Loop option and loop chosen segment ❌
- Multi-Language support ❌
- Boost volume ❌
- Nest/Group clips on the timeline ❌

<details>
<summary>Keybinds and Shortcuts 🔄️</summary>
  
- Alt+Left arrow key/ Alt+Right arrow key to move the selected clip ahead or behind to the other clip
- Shift+C to cut the clip where the playhead is located at
- DEL key works on many places
- Double click on any clip on the timeline to configure them individually
- CTRL+Z undo, Ctrl+Shift+Z redo
- Ctrl+Wheel to zoom in/out on the timeline
- F2 in project section to rename files on the disk
- Right click on Imported project videos to see additional options
- Copy/paste works on the timeline
- Keybinds will be added in the future ... 

</details>
