Description ⭐
-
[OPEN SOURCE] Cut, trim, merge video clips quickly with ease without launching a heavy program. Made for memes, gaming clips and similar basic use cases. Tired of not having a reliable program to do tasks that should take seconds? This is the answer for all of your problems. I made it for myself and everyone else too. Enjoy.

FAQ ❔
--
<details>
<summary><b>1. Why Should I use this program over X ?</b></summary>

I've made this program to do very simple tasks lightning fast, you will get the job done on here before you can start and import your files on an industry standard program. This doesn't mean this program is a competition nor an alternative. It's just a quick multi-tool for short and light tasks.
</details>

<details>
<summary><b>2. The X Program already does light edits, why does this program exists?</b></summary>

I already know there are couple of options for this kind of tasks and I've tried them all. Many has dated UIs, odd UI's that are hard to navigate through or get used to and some are straight-out too slow to do light tasks that I'd rather boot up an industry standard program instead. This program has been made for pure convenience. 

Lastly I have some extra features here where I can't see every alternative to have all these features I need. It's a quick multi-tool, "best of both worlds".
</details>

<details>
<summary><b>3. What's the use case for this program?</b></summary>

For example; you have couple of gaming clips and you want to merge them and cut-out some unnecessary parts, you can get it done in 1 to 3 minutes or less on this program

Or you have a your taskbar/titlebar showing in the video? Crop it out instantly! A segment you want to mute? done!

File size too big to share on discord? Compress it real quick with the social media presets! No need to swap between programs, all can be done in a single place without launching a program that takes minutes to load... Ad***e...
</details>

<details>
<summary>Keybinds and Shortcuts 🔄️</summary>
  
- Alt+Left arrow key/ Alt+Right arrow key to move the selected clip ahead or behind to the other clip
- Shift+C to cut the clip where the playhead is located at
- DEL key works on many places
- Double click on any clip on the timeline to configure them individually
- CTRL+Z undo, Ctrl+Shift+Z redo
- Ctrl+Wheel to zoom in/out on the timeline
- F2 in project section to rename files on the disk
- Right click on Imported project videos to see additional options
- Copy/paste works on the timeline
- Keybinds will be added in the future ... 

</details>
